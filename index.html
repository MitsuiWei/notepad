    GitHub 同步設定

    筆記會寫入私人倉庫 的 notes/notes.json。 網頁本身不含任何筆記內容，需要 Token 才能讀寫。

    如何建立 Token？
    1. 打開 GitHub → Settings → Developer settings → Fine-grained tokens
    2. Repository access 選「Only select repositories」，勾選
    3. Permissions → Repository permissions → Contents 設為 Read and write
    4. Generate token，複製貼到上方欄位

    Token 只存在這台瀏覽器的 localStorage，不會上傳到任何地方（除了 GitHub API）。
